# Eirunest · 项目简介

Eirunest 是一个面向长期陪伴的生成式 AI 角色研究原型，想验证的是：**陪伴感能否从机制中长出来**，而不是靠提示词演出一个性格。它把人格倾向、情绪与精力、关系经历、记忆、作息与信息可见范围收进一个持续演化的状态系统；其中最关键的一点是人格不写死——角色有一组会被经历改写的倾向（表达欲、黏人度、戒备心），相处推动它们，它们又反过来决定她之后的主动概率、害羞阈值、心情衰减与出门偏好。于是同一个预设，被回应得多的与被冷落得多的，会慢慢长成两个人，而这些变化在状态面板里可见、可回溯。交互上，她只在自己"刷手机"时读到你的动态，再自主决定是否回应、隔多久回应；你离开的这段时间她照自己的日程继续生活，回来时你能翻到她留下的照片、朋友圈与记忆，而不是一句"她一直在等你"；你也可以通过仿微信界面观察她的日常，并以触摸、注视等身体化方式与她互动。技术上，生成模型只输出受限的台词与情绪、动作意图，数值、日程、事件与存档均由确定性引擎独立控制并校验，模型无法直接改写状态，离线时由规则兜底。未来我想推进两个方向：把文化价值与社会规范做成角色可检索、可权衡的决策依据，并引入多视角协商与定向微调；以及把现在"按日程重演"的离场推进，扩展为显式的事件因果图与多角色关系网络。
