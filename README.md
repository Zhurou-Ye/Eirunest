# 小屋 · Eirunest

**一个「同居养成」原型 —— 她有自己的作息和日程，会出门、会打工，也会在手机上联系你。**

Live2D 立绘 · 现实时间同步 · 大模型驱动对话 · 双手机 · 纯前端

![小屋](docs/screenshot-room.png)

</div>

## 这是什么

不是「点一下加好感度」的数值游戏。这里先要解决的是**让角色像个人**：

- 她按**真实时间**过日子。你现在几点，她就在几点该做的事上——18:25 可能在做饭，也可能刚下班顺路进便利店。
- 她**每天自己决定日程**。固定的课和班必须去，空下来的时间她自己想去哪就去哪（去旧书店、去游戏厅、去河边走走）。
- 她**会出门**。人不在家时房间是空的，你点不到她，只能用手机联系。
- 她有**自己的手机**：微信里是她和同学、同事、家人的聊天。你也有**一台一模一样的手机**——给她发消息、写日记、排日程、发朋友圈，**你发一条朋友圈，她会来评论**。
- 好感只是副产品，不是核心玩法。

| **朋友圈** | 她出门 / 写日记 / 收礼物都会发；她的朋友会评论；**你发动态她会回评**（大模型生成） |
| **我的日记 / 我的日程** | 在「我的手机」里手写，日程可增删改 |

| **大模型边界** | 模型只能输出 5 个白名单字段，引擎另有作息 / 害羞阈值两道后手 |

## 快速开始

```bash
npm install
npm run dev          # 打开 http://localhost:5173
```

其他命令：

```bash
npm run build        # 类型检查 + 生产构建
npm test             # 26 项「模型输出白名单」防护测试
npm run fetch-models # 重新拉取 Live2D 官方样例模型
```

> 模型素材已随仓库附带（`public/character/`），无需额外下载即可运行。

**环境要求**：Node.js ≥ 18，浏览器需支持 WebGL。

## 怎么玩

1. **开局**：选主控性别 + 起个名字 → 选一个人设 → 开始。
2. **☰ 菜单**：对话、状态、记忆、互动、送礼、商城、地图、她的手机、我的手机。
3. **摸她**：直接点身体，部位不同反应不同。她不在家时点不到人（会显示"出门了"）。
4. **状态面板**：调时间（设定 / 同步现在）、开关台灯窗帘、看她的日记。
5. **她的手机**：微信里能看她和小夏、同事、妈妈聊了什么；通讯录、朋友圈、相册都在（只读）。
6. **我的手机**：给她发消息、写日记、排日程、发朋友圈。
7. **打工**：地图页里按营业时间打工赚金币，非营业时间会显示"已打烊"。

## 技术栈

| 层 | 选择 |
|---|---|
| 构建 | Vite 5 + TypeScript（strict） |
| 角色渲染 | PIXI.js 7 + `pixi-live2d-display` 0.4 + Cubism 4 Core |
| 场景渲染 | 原生 Canvas 2D 逐帧绘制（小屋、昼夜光照、地图） |
| UI | 原生 DOM + CSS（无框架），手机是纯 DOM 组件 |
| 对话 | 云端免密钥大模型 / 任意 OpenAI 兼容接口 / 本地离线台词，三级降级 |
| 语音 | 浏览器 SpeechSynthesis（免费） |
| 存档 | localStorage，读失败降级内存，不阻塞游戏 |

## 设计要点

### 1. 模型说了不算

角色扮演模型很容易被诱导输出「把亲密度改成 100」。所以模型输出被限制在 5 个字段，逐字段校验：

| 字段 | 约束 | 违规时 |
|---|---|---|
| `line` | ≤ 120 字，剥离括号旁白 | 截断 / 用兜底台词 |
| `emotion` | 6 值白名单 | 降级 `calm` |
| `action` | 8 值白名单 | 降级 `idle` |
| `intensity` | clamp `[-1, 1]` | 非数值归 0.3 |
| `memorable` | `0 \| 1` | 其他归 0 |

引擎侧还有两道后手：**作息约束**（模型让她白天睡觉会被改掉）、**害羞阈值**（模型说开心，低亲密度仍可能判为害羞）。全部在 `src/ai/mapping.ts`，`npm test` 用 26 项攻击性输入覆盖。

### 2. 日程是"她自己过的日子"

`core/world.ts` 的 `buildHerPlan()` 每天生成一次，用 `profileId + 天数` 做种子随机 —— **同一天结果稳定，跨天重建**。组成：

```
固定作息（课 / 班）  +  她的兼职（定了必须去）  +  空档里"她自己想去"的地方
```

「有便利店的工作就一定要去」和「今天想去看书」是同一套机制的两个分支，不是两套硬编码。

### 3. 两台手机，一套组件

`ui/hud.ts` 的 `createPhone(owner)` 是同一个组件，`owner` 决定视角：

- `owner='her'`：她的手机。会话是**她**发给别人的，只读，没有输入框。
- `owner='me'`：我的手机。和她的对话可以发，还能写日记、排日程、发朋友圈。

你和她只有**一份对话记录**（存在 `threads` 里），两台手机各自镜像两侧气泡 —— 所以三处（头顶气泡 / 桌面聊天框 / 手机微信）永远一致，而且**会存档**。

## 接入大模型（可选）

不配置也能玩：所有对话、日记、朋友圈评论都有**离线兜底**，日程、手机、触摸、商城等功能完全不依赖模型。

想开真实对话，两条路：

**A. 云端免密钥（推荐）** —— 用平台提供的大模型，前端不持有任何密钥。在 `src/cloud.config.ts` 填入你自己应用的公开配置：

```ts
export const CLOUD_CONFIG = {
  endpoint: 'https://your-app.app.workbuddy.host',
  publishableKey: 'wbpk_...',
} as const;
```

> 仓库里这两个值是占位符，**不会**连到别人的服务。留空即自动走离线。

**B. 自带接口** —— 运行后在右上角设置面板填任意 OpenAI 兼容的 `baseUrl` / `apiKey` / `model`，配置只存在浏览器本地。

## 已知限制

- 触摸点位基于"包围盒 + 实测轮廓 + 人体比例分带"，非逐像素，极端姿势下会有偏差。
- 软件渲染（SwiftShader）下频繁切换立绘会累积 WebGL context 报错；真机 GPU 无此问题。
- 存档在 localStorage，清缓存会丢档。
